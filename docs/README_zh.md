# TheySay - Twitter / X 推文抓取器 (Electron App)

[English](../README.md) | [中文说明](README_zh.md)

一个基于 Electron 的 4 栏多账号并发 Twitter / X 推文监控看板：
- **4 栏独立网格**：界面划分为 4 个独立面板（2×2 布局），每个面板可填入一个 Twitter handle，且配有独立的纵向滚动条浏览推文。
- **Handle 自动持久化**：在输入框填入的用户 handle 会自动实时存储在 `localStorage` 中；按 <kbd>Cmd + R</kbd> 刷新应用或重启时，填入的内容与推文缓存会原样完整保留。
- **后台真正并行抓取**：底层为每个栏目分配了独立的后台离屏 webview，4 栏同时抓取时互不干扰，支持一键“全部并行抓取”。
- **弹窗登录**：右上角提供登录状态感知与弹窗登录，登录凭据通过 `persist:x_session` 在所有后台抓取器间持久化共享。

## 运行方法

在项目根目录下执行：

```bash
npm install
npm start
```

## 功能特点

1. **4 栏多用户监控看板**：
   - 采用 2×2 网格，视野清晰，每个栏目拥有独立的输入框、抓取按钮与结果滚动视口；
   - 顶部提供 **“全部并行抓取”** 快捷按钮，支持一键触发 4 个用户推文的并发获取；
   - 支持单条推文复制、在系统默认浏览器中打开原推以及一键复制单栏全部推文。
2. **Handle 与缓存持久化**：
   - 每次输入自动保存，刷新页面（<kbd>Cmd + R</kbd>）不会丢失已填的用户名及已加载的推文数据。
3. **多 Webview 并行并发**：
   - 内置 4 个独立的后台离屏 webview 实例，全部共享登录态，实现真正的多用户并发抓取与虚拟列表滚动。
