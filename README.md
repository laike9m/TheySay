# TheySay

**TheySay** is a multi-column desktop dashboard for monitoring multiple Twitter / X accounts and Discord channels side by side in real time.  
**TheySay** 是一款多栏桌面监控看板，支持在网格布局中同时实时追踪多个 Twitter / X 账号与 Discord 频道。

## Features / 功能介绍

- **Multi-Platform Grid Dashboard**: Monitor Twitter / X accounts and Discord channels (public or private) side by side in a drag-and-drop, resizable grid.  
  **多平台网格看板**：支持在可自由拖拽、调整尺寸的网格中并排监控多个 Twitter / X 博主与 Discord 频道（含私有频道）。

- **Telegram-Style Feed & Popup Reader**: Read updates in clean chronological chat bubbles, and click any post to view the full text or high-resolution images in a centered popup.  
  **Telegram 风格对话流与弹窗阅读**：以清爽的对话气泡按时间流展示最新消息，点击任意气泡即可居中弹出详情卡片阅读全文或查看高清大图。

- **Smart Stock & ETF Ticker Highlighting**: Automatically detects and highlights US stock, ETF, and crypto tickers (with or without `$`) with customizable badge colors and NASDAQ symbol sync.  
  **股票与 ETF 代码智能高亮**：自动识别并高亮消息中的美股、ETF 及加密货币代码（无论是否带 `$` 前缀），支持自定义配色与 NASDAQ 词库在线同步。

- **Unread Tracking & Per-Channel Notifications**: Highlights new messages with unread count badges and lets you toggle desktop notifications independently for each account or channel.  
  **未读提醒与按频道独立通知**：自动高亮新消息并显示未读计数角标，支持为每个账号或频道单独开启桌面系统通知。

- **Custom Auto-Refresh & Profile Backup**: Set independent background refresh intervals for Twitter and Discord, and export or import your entire layout, settings, and followed list as a `.json` profile anytime.  
  **独立自动刷新与 Profile 备份**：支持分别为 Twitter 与 Discord 设置后台刷新频率，并可将全部排版、设置与关注列表一键导出/导入为 `.json` 备份文件。

- **Bilingual Interface (English & Chinese)**: Automatically adapts to your system language (defaults to English unless your system is set to Simplified or Traditional Chinese), with instant language switching in Settings.  
  **中英双语界面**：自动根据系统语言切换界面语言（系统为简/繁体中文时默认显示中文，其他语言环境默认显示英文），并支持在设置中随时手动切换。
