# TheySay - Twitter / X 推文抓取器 (Electron App)

[English](../README.md) | [中文说明](README_zh.md)

基于 Electron 与 [GridStack.js](https://gridstackjs.com/) 构建的动态可拖拽 Twitter / X 多账号推文看板：
- **深色 / 浅色模式一键切换**：顶栏原生支持 Dark Mode 与 Light Mode 切换，主题偏好自动保存。
- **支持 2×2 到 4×4 灵活网格切换**：支持在 `2×2`、`2×3`、`3×2`、`3×3`、`4×4` 间自由无缝切换，格子数量严格匹配所选网格。
- **卡片 Header 集成头像与博主名字（精简去除冗余名字栏）**：Header 高度压缩至 34px，博主姓名与 handle 紧随头像在 Header 原生展示，点击即可切换/修改账号；彻底移除独立的次级状态栏，推文直顶 Header。
- **滚动条默认隐藏**：每个卡片的滚动条默认保持隐形，只有当鼠标移入卡片区域时才淡入，界面更加干净简洁。
- **多样化尺寸选项 (`行 × 列`：`1×1`, `2×1 纵向双行`, `3×1 纵向三行`, `2×2 双行双列`)**：遵循“行在前、列在后”的标准几何矩阵定义。
- **智能周边内容防冲撞检测**：放大时若目标区域周边格子已有监控账号内容，自动拦截并弹出提示，同时在界面上以红色微震动高亮标出冲突卡片，提示用户先移开或清空。
- **排版与输入持久化保存**：Twitter handle、已抓取的推文缓存、头像以及自定义拖拽后的网格坐标均实时存入 `localStorage`，刷新应用（<kbd>Cmd + R</kbd>）原样完整还原。
- **按需懒加载静默抓取与终端报错修复**：按需分配离屏 Webview，消除启动时 16 个辅助进程造成的资源浪费与 macOS 平台 Chromium 底层报错。

## 运行方法

在项目根目录下执行：

```bash
npm install
npm start
```

## 功能特点

1. **界面极致美化、主题切换与头像/姓名集成**：
   - 顶部导航栏提供深色 / 浅色模式切换按钮（☀️/🌙），自适应系统风格与 Twitter 经典调色板；
   - 降低卡片 Header 高度至 34px，在头像旁原生展示博主姓名、handle 与推文计数，点击姓名可直接激活修改输入框；
   - 彻底移除卡片下方独立的“名字那一栏”（Status Bar），为推文列表腾出宝贵的纵向阅读空间；
   - 卡片滚动条默认完全隐藏，鼠标悬停时平滑显现。
2. **多尺寸卡片与防冲突排版**：
   - 点击卡片右上角尺寸菜单，可选择 `1×1`（单格）、`2×1`（纵向双行）、`3×1`（纵向三行）、`2×2`（双行双列）尺寸；
   - 冲撞防护：检测目标位置是否被已有账号内容的格子占据，若有冲突则禁止覆盖，并通过红框震动与顶部 Toast 引导用户移开或清空。
3. **严格网格同步与自由拖拽**：
   - 切换网格布局时严格按照目标网格数量生成，清理所有多余残留格子；
   - 拖拽卡片：按住顶栏把手 `⠿` 即可自由拖动卡片重新排序；
   - 预设切换：顶部下拉菜单快速切换网格，支持一键“重置排版”。
4. **Handle、缓存与布局持久化**：
   - 每次输入与排版调整自动实时保存，刷新页面（<kbd>Cmd + R</kbd>）保留所有状态。
5. **按需后台离屏 Webview 并发**：
   - 采用按需懒加载机制，仅对实际抓取的卡片创建后台 Webview；修复 macOS 下 Chromium 的 task_policy_set 与 Mojo Widget 终端报错，支持顶部“全部并行抓取”。
6. **拟人化随机延迟与防风控感知**：
   - **错峰启动**：一键并行抓取时按 `200ms ~ 450ms` 阶梯随机错峰，消除机械式的突发流量峰值；
   - **随机平滑滚动**：每次动态滚动 `650px ~ 1050px`，并加入平滑滚动动画；
   - **阅读停顿模拟**：滚动后模拟人眼停留阅读 `300ms ~ 600ms`；
   - **风控主动识别**：自动感知 Arkose Labs 人机验证挑战或 Rate limit 限制，提供即时指引。
