# TheySay - Twitter / X 推文抓取器 (Electron App)

[English](../README.md) | [中文说明](README_zh.md)

基于 Electron 与 [GridStack.js](https://gridstackjs.com/) 构建的动态可拖拽 Twitter / X 多账号推文看板：
- **统一“登录账号”下拉菜单与 Profile 导出/导入**：顶栏将 Twitter / X 与 Discord 等各平台登录入口整合为统一的“登录账号”下拉 Popover 菜单。实时显示各平台登录状态徽章（已登录 / 未登录 / 检测中）及全局发光状态点，点击可弹出对应平台登录/切换账号窗口，并提供快捷的 **导出 Profile** 与 **导入 Profile** 入口。
- **Profile 全量备份（全部设置 + 关注列表）与切换账号保留已抓取数据**：支持在顶栏“登录账号”菜单或“偏好设置”弹窗中一键导出/导入 `.json` 格式的 Profile 配置文件，包含全部偏好设置（深浅主题、网格布局预设、卡片位置与尺寸、Twitter/Discord 刷新频率、仅会员推文过滤、Discord 提示音开关、Title 栏配色、Ticker 高亮配色及各卡片通知静音状态）以及所有关注的 Twitter 博主与 Discord 频道。**切换账号绝不清除已抓取的数据**：无论是切换已登录的 Twitter/Discord 账号、在卡片中修改/切换监控的博主或频道、编辑输入框时点击清空，还是导入新的 Profile，所有已抓取的历史推文与频道消息都会按目标账号/频道持久归档在本地缓存（`theysay_target_cache`）中，切回时秒级无损恢复。
- **偏好设置弹窗与独立平台刷新频率配置**：顶栏“登录账号”左侧新增齿轮设置按钮，点击居中弹出偏好设置 Modal。支持分别独立配置 Twitter / X 与 Discord 各自的后台自动刷新频率（预设 30 秒、1 分钟、2 分钟、3 分钟、5 分钟、10 分钟、15 分钟、30 分钟、1 小时，或自定义分钟数），内置防风控安全提示与一键恢复默认，保存后即刻重载轮询调度器。
- **仅会员可见帖子识别与独立显示过滤**：智能识别 Twitter / X 创作者会员/订阅专享推文（如带有“Subscribe to unlock / 订阅以解锁”或 Super Follows 的帖子），在时间线气泡中以琥珀金色【仅会员】专属徽章醒目标注，点击弹窗支持即时呈现会员专享卡片与一键直达原推文；偏好设置内新增“是否显示仅会员可见的帖子”配置选项，支持选择显示或自动过滤隐藏，保存后实时重载刷新所有卡片，无需重启应用。
- **Ticker 股票代码智能高亮与自定义前景色/背景色**：自动识别 Twitter 与 Discord 消息文字中的美股、ETF 及加密货币 Ticker，同时支持 `$ZETA`、`$nvda` 等带 `$` 前缀代码以及不带 `$` 的大小写代码（如 `SMTC`、`muu`、`mu`、`uctt`、`spcx`、`intc`），内置并支持从 NASDAQ 官方接口在线同步 9,600+ 个美股与 ETF 词库（自动过滤 `put`、`call`、人名与普通英文单词）。匹配到的 Ticker 自动加粗并添加醒目背景底色；在偏好设置中提供 6 套一键预设配色以及自由可选的前景色（文字颜色）与背景色（底色）取色器及实时预览。
- **Discord 通知声音开关**：后台离屏运行的 Discord 客户端在收到私信、@提及等消息时仍会播放 Discord 自带的提示音。偏好设置中新增“Discord 通知声音”选项，设为“关闭 (静音)”即可将后台 Discord Webview 整体静音；保存后立即生效并持久化保存，完全不影响频道消息抓取。
- **深色 / 浅色模式切换与可定制卡片标题栏配色**：顶栏原生支持精致平滑的胶囊 Toggle 开关（☀️/🌙 图标自适应切换），主题偏好自动持久化保存。偏好设置中新增“卡片标题栏配色”板块，内置 6 套精选候选配色（**深邃暗夜蓝 `#1e293b`**、**经典天青蓝 `#2563eb`**、**温暖亚麻米 `#f3ede2`**、**清新薄荷绿 `#dff2ea`**、**雾光薰衣草紫 `#eae6f9`**、**暖阳奶油杏 `#faeed4`**）以及自由取色器，支持点击时实时预览看板效果并根据底色明度自动适配深/浅文字与图标颜色，与纯白/未读蓝消息气泡清晰区分。
- **Telegram 风格聊天气泡与日期分界条**：高度拟真 Telegram 对话气泡质感与日期分组，每天推文上方居中显示半透明胶囊日期条（如 `June 29, 2025`），且同一天的多条推文仅显示一个日期头部；气泡随内容自适应包裹收缩（最大宽度 88%），去除了重复头像与消息编号，具体时间戳优雅内联于文字右下角（如 `11:45 AM`），鼠标悬停时光标所在气泡右上角浮现跳转原推文按钮（`↗`）。
- **长推文截断、引用识别与预渲染纯净 Embed 点击弹窗**：长推文默认仅展示前 100 个字符以保持气泡紧凑整洁，并支持精准识别带引用的推文（带紫色"引用"标识）；移除了在气泡内部直接展开导致下方推文被挤压下移的旧逻辑，改为在鼠标点击推文气泡时，在应用中央以纯净无外边框的 Modal 悬浮层直接呈现 Twitter/X 官方嵌入推文。在嵌入卡片内部，点击 **"Show more"** 可直接在当前弹窗内原地展开完整长推文（`note_tweet`），不再跳转到外部浏览器；同时改变了原官方卡片点击任意空白或文字即跳转浏览器的行为，现在点击或划选正文文字区域不会打开浏览器，**仅点击右上角 `𝕏` 图标或底部 `Read X replies` 按钮**时才在外部浏览器中打开。官方卡片采用**后台预渲染**策略：动态加载完成后在空闲时段静默预渲染最新推文，鼠标悬停气泡时该推文会被提升至渲染队列最前，因此点击时卡片通常已经就绪。每条推文在弹窗内拥有各自常驻的宿主元素，切换显示仅通过纯 CSS 类完成，iframe 全程不发生跨父节点搬移（搬移会强制 iframe 重新加载），因此不存在"占位卡片先显示、官方卡片再替换"的突兀过程；配合 Electron 主进程重写 Cache-Control 实现静态资源长达 1 年的磁盘强缓存，二次打开同一条推文可 0ms 瞬间响应。点击弹窗周边的半透明遮罩区域或按下 <kbd>Esc</kbd> 键即可随时快速关闭。
- **卡片 Header 集成头像、博主名字与按频道独立的系统通知 Mute 按钮（默认 Mute）**：Header 高度压缩至 34px，博主姓名与 handle 紧随头像（支持精确按账号提取个人专属高清头像，彻底杜绝侧边栏推荐或转推头像干扰）在 Header 原生展示，点击即可切换/修改账号并按回车抓取；去除手动刷新按钮，替换为按频道/账号独立控制的系统通知静音开关（`🔕` / `🔔`，默认处于 Mute 静音状态）。点击开启某频道通知后，当该 Twitter 账号或 Discord 频道抓取到新消息时自动推送系统原生通知，点击系统通知即可唤醒主窗口并自动定位高亮对应卡片。
- **滚动条默认隐藏**：每个卡片的滚动条默认保持隐形，只有当鼠标移入卡片区域时才淡入，界面更加干净简洁。
- **多样化尺寸选项 (`行 × 列`：`1×1`, `2×1 纵向双行`, `3×1 纵向三行`, `2×2 双行双列`)**：遵循“行在前、列在后”的标准几何矩阵定义。
- **同列空白点击丝滑增高与挤压动效（再次点击 / 20 秒停留 / Header 悬停自动复原）**：点击某个 section 内容区的空白空间（非消息气泡区域）时，自动丝滑增加该 section 的高度，并将同一列（column）的其余 sections 挤压至原本高度的一半（`0.5×`）；再次点击已展开 section 的空白空间、在同一个 section 停留超过 20 秒，或将光标移至卡片顶部 Header（用户名那栏）时，均自动平滑复原原始高度。
- **智能周边内容防冲撞检测**：放大时若目标区域周边格子已有监控账号内容，自动拦截并弹出提示，同时在界面上以红色微震动高亮标出冲突卡片，提示用户先移开或清空。
- **增量智能抓取（避免重复拉取）**：抓取时自动比对已缓存的推文边界，如果遇到已经抓取过的推文立即停止滚动并完成合并；若无新推文则 ~1 秒内极速响应，大幅节省流量并降低触发限流概率。
- **窗口尺寸位置、排版、静音状态与输入持久化保存**：主窗口拖拽调整后的宽高尺寸、屏幕坐标及全屏/最大化状态实时持久化至 `userData/window-state.json`，重启应用自动还原上次窗口大小；Twitter handle、Discord 频道链接、各频道通知 Mute 状态、已抓取的推文缓存、头像以及自定义拖拽后的网格坐标均实时存入 `localStorage`，刷新应用（<kbd>Cmd + R</kbd>）原样完整还原。
- **未读新消息高亮、卡片蓝色圆形未读角标与一键“全部已读”**：新抓取的推文或 Discord 消息气泡背景以专属柔和蓝高亮区分，同时在每个卡片 Header 名字右侧显示 Twitter 风格的蓝色圆形未读条数提醒角标；鼠标悬停气泡自动消除高亮并实时递减未读数，点击卡片上的蓝色角标可将该栏全部标记为已读，顶栏双对勾（`✓✓`）“全部已读”按钮则支持一键清空全局未读状态。
- **后台定时轮询（10 分钟）与时间记录**：每次抓取均自动记录时间，卡片标题 Tooltip 实时显示上次抓取时刻；页面刷新（<kbd>Cmd + R</kbd>）绝不突发抓取，智能依据上次抓取时间计算剩余倒计时进行下一次轮询。

## 运行方法

在项目根目录下执行：

```bash
npm install
npm start
```

## 功能特点

1. **Telegram 风格聊天气泡与日期分界条**：
   - 完美复刻 Telegram 对话气泡美学：气泡宽度随文字长短自适应延伸（最大 88%），去除了冗余的消息编号与内嵌头像，具体时间戳（`11:45 AM`）原生内联于文字右下角最后一行；
   - 居中胶囊日期分界条：在每一天的推文消息上方显示居中半透明胶囊日期条（如 `June 29, 2025`），严格遵循同一天的气泡仅显示一个日期头部；
   - 采用符合 IM 习惯的时间升序排布（从上到下是从旧到新，最新推文位于底部），并自动滚动至最新消息处；
   - 鼠标悬停到推文气泡上时，右上角浮现跳转原推文链接按钮（`↗`）；
   - 截断推文（>100 字符）与引用推文居中弹窗：彻底摒弃了气泡原地伸展破坏阅读流的旧交互，点击推文气泡即可在屏幕中央以纯净无边框悬浮层展示完整原始推文，避免 hover 误触；在弹窗卡片内支持点击 **"Show more"** 原地展开完整长推文，点击或选中正文文字不会误触打开浏览器，仅点击右上角 `𝕏` 标志或底部 `Read X replies` 按钮才会调用外部浏览器打开；点击弹窗外围遮罩区域或按下 <kbd>Esc</kbd> 即可平滑退出。
2. **界面极致美化、主题切换、Title 栏配色与按频道系统通知 Mute 按钮**：
   - 顶部导航栏配备动效 Toggle 开关（☀️/🌙），自适应系统风格与 Twitter 经典调色板；
   - 偏好设置内置“Title 栏背景配色”选项，提供 6 套精选候选配色与自由取色器，点击即可在弹窗内及背后看板实时预览，自动根据背景深浅适配白字/深色字；
   - 降低卡片 Header 高度至 34px，在头像旁原生展示博主姓名与 handle，点击姓名可直接激活修改输入框；
   - 移除了手动刷新按钮，在卡片右上角配备按频道独立控制的系统通知 **Mute 开关按钮**（默认 **Mute 静音**）。点击即可为指定 Twitter 博主或 Discord 频道单独开启/关闭 macOS 系统原生通知，点击弹出的系统通知可一键唤起应用并定位高亮对应卡片；
   - 彻底移除卡片下方独立的“名字那一栏”（Status Bar），为推文列表腾出宝贵的纵向阅读空间；
   - 卡片滚动条默认完全隐藏，鼠标悬停时平滑显现。
3. **增量抓取机制（智能去重与极速检测）**：
   - 每次抓取优先比对当前卡片已存在的推文集合，一旦触达已知边界立即终止下滚；
   - 仅拉取比上次更新发布的“新推文”并追加到列表顶部，无新推文时 ~1 秒内闪电完成，极大减少无意义滚动与被 Twitter 风控限流的风险。
4. **多尺寸卡片、同列悬停丝滑缩放与防冲突排版**：
   - 点击卡片右上角尺寸菜单，可选择 `1×1`（单格）、`2×1`（纵向双行）、`3×1`（纵向三行）、`2×2`（双行双列）尺寸；
   - 同列悬停丝滑增高与挤压：把光标从一个 section 移至另一个 section 时，当前 section 高度丝滑增加，并将同列其它 sections 挤压至原高度的一半；在同一 section 停留满 20 秒或移入卡片 Header（用户名栏）时自动平滑复原；
   - 冲撞防护：检测目标位置是否被已有账号内容的格子占据，若有冲突则禁止覆盖，并通过红框震动与顶部 Toast 引导用户移开或清空。
5. **严格网格同步与自由拖拽**：
   - 切换网格布局时严格按照目标网格数量生成，清理所有多余残留格子；
   - 拖拽卡片：按住顶栏把手 `⠿` 即可自由拖动卡片重新排序；
   - 预设切换：顶部下拉菜单快速切换网格布局，按需自动整齐排列。
6. **Discord 频道监控（公开发言与私有受限频道）**：
   - 支持将任何 Discord 频道链接（如 `https://discord.com/channels/100000000000000001/200000000000000002`）直接粘贴到任何卡片输入框中；
   - 自动识别 Discord 链接，输入框前缀智能从 `@` 切换为 `#`，标题自动解析为 `#频道名` 与服务器名称；
   - **私有频道授权登录**：顶栏“登录账号”下拉菜单提供专用的 Discord 授权登录入口，使用独立的会话分区（`persist:discord_session`），登录后即可无缝监控需要成员身份的私有 Guild 频道；
   - **Telegram 风格群聊视觉美化与气泡内嵌图片预览**：采用 Telegram 风格群聊气泡，基于用户名为每位发言者分配专属色彩，连续同一人发言自动折叠作者信息，优雅渲染回复引用（`↩ author: text`），在气泡内直接显示单图/多图网格预览，并对视频/附件/嵌入卡片提供标签摘要；
   - **居中消息详情、可点击链接与大图弹窗**：点击任何 Discord 聊天气泡即可居中弹出消息卡片，完整阅读全文（卡片内链接支持直接点击在默认浏览器打开）、查看高清大图（点击图片可在浏览器打开原图）、引用信息和附件，并提供在 Discord 网页或客户端一键直达原消息的跳转按钮；
   - **单例共享 Webview、智能频道切换与状态强校验**：所有 Discord 槽位共享一个后台轻量 Webview，同服务器内秒级无缝切换，跨服务器自动重载，保留网关长连接并极大降低内存占用。具备严格的频道与消息 ID 校验及缓存自愈机制，杜绝 DOM 滞后与跨频道消息串台。
   - **通知声音开关**：在偏好设置中将“Discord 通知声音”设为“关闭 (静音)”，即可通过 `setAudioMuted` 将后台 Discord 客户端发出的所有声音整体静音；保存后即刻生效，客户端重新加载时自动重新应用，默认保持开启。
7. **Profile 导出/导入、切换账号无损保留数据与全方位持久化**：
   - **一键导出 / 导入 Profile**：可将全部设置（深浅色主题、网格预设与各卡片尺寸坐标、Twitter/Discord 刷新频率、会员帖显示开关、Discord 通知声音、Title 栏配色、Ticker 高亮配色、各槽位通知 Mute 状态）与所有关注的 Twitter 账号 / Discord 频道完整导出为 JSON 文件，随时在“登录账号”菜单或“偏好设置”弹窗中一键导入恢复。
   - **切换账号不清除已抓取数据**：所有抓取到的推文与 Discord 消息除按槽位缓存外，同时按唯一目标标识（`twitter:<handle>` / `discord:<guildId>/<channelId>`）持久归档至 `theysay_target_cache`。无论是在卡片内切换监控的博主/频道、编辑输入框时点击 `✕` 重新输入、在顶栏切换登录的 Twitter/Discord 账号，还是导入切换不同 Profile，已抓取的数据均完整保留，切回原账号时立即从缓存无损还原。
   - 自动记录并恢复主窗口拖拽调整后的宽高尺寸（`width`、`height`）、位置坐标（`x`、`y`）及全屏状态（持久化至 `userData/window-state.json`，内置多显示器边界防越界检测）。
   - 每次输入 Twitter handle 或 Discord 频道链接、切换频道通知 Mute 状态、卡片排版自动实时保存，刷新页面（<kbd>Cmd + R</kbd>）或重启应用保留所有状态与消息缓存。
8. **独立后台定时轮询与刷新频率设置（Twitter 与 Discord 分离）**：
   - 顶栏“登录账号”左侧常设齿轮设置按钮（`⚙️`），点击居中呼出偏好设置面板；
   - 分离配置：支持分别独立调节 Twitter / X 与 Discord 各自的自动刷新频率，提供常用梯度预设（`30秒`、`1分钟`、`2分钟`、`3分钟`、`5分钟`、`10分钟`、`15分钟`、`30分钟`、`1小时`）与自定义分钟输入；
   - 智能防风控提示：针对 Twitter 频率限制风险贴心提示推荐周期（建议 5 分钟以上），支持一键“恢复默认”；
   - 调度器热重载：点击保存后即刻存入 `localStorage`，定时轮询任务无缝重新排期生效，无需重启应用；
   - 记录每次抓取时间：卡片标题悬停实时查看精准抓取时间（如 `上次抓取: 15:09:23`），并持久化到本地存储；
   - 页面刷新不立刻触发抓取：刷新或启动应用时，优先展示本地缓存内容，并自动计算距离上次抓取的时间差，在倒计时归零前绝不突发重复请求，彻底避免频繁刷新造成的风控限流；
   - 采用平滑依次抓取机制（非并发突发请求），账号间设置适度礼貌间隔；抓取前自动检测网络连通性与 DNS 解析状态，断网或休眠期间自动跳过抓取；采用按需懒加载离屏 Webview 机制，修复 macOS 底层报错。
9. **仅会员可见帖子识别与显示过滤设置**：
   - **智能识别**：精准嗅探创作者订阅与解锁链接（`/superfollows/subscribe`）、解锁按钮文本以及中英文订阅引导语（`Subscribe to unlock` / `订阅以解锁` 等）；
   - **时间线醒目标注**：在推文气泡上以精致的琥珀金色【仅会员】徽章清晰标出，与置顶、转推、引用推文形成鲜明层级区分；
   - **偏好设置与动态过滤**：在偏好设置弹窗中提供“显示仅会员可见的帖子”下拉选项，可按需设为“显示（标出【仅会员】）”或“不显示（自动过滤）”；
   - **实时热重载**：保存设置后无需刷新页面或重新抓取，所有已加载卡片即刻同步更新显示；若某账号当前推文全部为会员帖且被隐藏，气泡列表将友好展示提示信息；
   - **即时弹窗详情卡片**：会员帖公共 Widget 通常无法直接公开加载，点击会员推文气泡可即时居中呼出详情弹窗卡片，展示【仅会员可见】提示与正文，并提供一键跳转至 Twitter/X 官方网页进行解锁的按钮。
10. **Ticker 股票代码高亮与自定义配色**：
    - **三级大小写智能识别**：第一级直接匹配显式 `$TICKER`（如 `$ZETA`、`$nvda`）；第二级基于内置及在线同步的 NASDAQ 美股与 ETF 代码库无条件识别非普通单词的代码（支持全大写或全小写，如 `SMTC`、`muu`、`mu`、`uctt`、`spcx`、`intc`）；第三级结合交易语境（如止盈、加仓、建仓、价格数字）智能识别与英文单词重名的热门代码（如 `coin`、`hood`、`spy`），同时精准排除 `put`、`call`、普通英文词汇与昵称称呼（如 `pike老师`）。
    - **永久留存词库 + NASDAQ 官方接口按需同步**：在 `data/ticker-data.json` 中持久保存 9,600+ 个过滤后的美股与 ETF 代码，每次向 `api.nasdaq.com` 同步的新上市股票与 ETF 均永久合并写入本地词库，永不过期失效。
    - **前景色与背景色自由可选**：偏好设置中提供 6 套精选配色预设（琥珀金、荧光黄、看涨绿、电光蓝、霓虹紫、朱砂红），并支持通过取色器或 Hex 色值自由定制 Ticker 的前景色（文字颜色）与背景色（高亮底色），配备实时预览。
11. **拟人化随机延迟与防风控感知**：
    - **平滑轮询间隔**：账号间抓取保持适度缓冲等待，消除机械式的突发流量峰值；
    - **随机平滑滚动**：每次动态滚动 `650px ~ 1050px`，并加入平滑滚动动画；
    - **阅读停顿模拟**：滚动后模拟人眼停留阅读 `300ms ~ 600ms`；
    - **风控主动识别**：自动感知 Arkose Labs 人机验证挑战或 Rate limit 限制，提供即时指引。
