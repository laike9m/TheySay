# TheySay - Twitter / X 推文抓取器 (Electron App)

[English](../README.md) | [中文说明](README_zh.md)

基于 Electron 与 [GridStack.js](https://gridstackjs.com/) 构建的动态可拖拽 Twitter / X 多账号推文看板：
- **统一“登录账号”下拉菜单**：顶栏将 Twitter / X 与 Discord 等各平台登录入口整合为统一的“登录账号”下拉 Popover 菜单。实时显示各平台登录状态徽章（已登录 / 未登录 / 检测中）及全局发光状态点，点击可弹出对应平台授权登录窗口；避免平铺按钮占用导航栏过多空间，便于未来扩展更多平台。
- **偏好设置弹窗与独立平台刷新频率配置**：顶栏“登录账号”左侧新增齿轮设置按钮，点击居中弹出偏好设置 Modal。支持分别独立配置 Twitter / X 与 Discord 各自的后台自动刷新频率（预设 30 秒、1 分钟、2 分钟、3 分钟、5 分钟、10 分钟、15 分钟、30 分钟、1 小时，或自定义分钟数），内置防风控安全提示与一键恢复默认，保存后即刻重载轮询调度器。
- **深色 / 浅色模式动效 Toggle 切换**：顶栏原生支持精致平滑的胶囊 Toggle 开关（☀️/🌙 图标自适应切换），主题偏好自动持久化保存。
- **Telegram 风格聊天气泡与日期分界条**：高度拟真 Telegram 对话气泡质感与日期分组，每天推文上方居中显示半透明胶囊日期条（如 `June 29, 2025`），且同一天的多条推文仅显示一个日期头部；气泡随内容自适应包裹收缩（最大宽度 88%），去除了重复头像与消息编号，具体时间戳优雅内联于文字右下角（如 `11:45 AM`），鼠标悬停时光标所在气泡右上角浮现跳转原推文按钮（`↗`）。
- **长推文截断、引用识别与预渲染纯净 Embed 点击弹窗**：长推文默认仅展示前 100 个字符以保持气泡紧凑整洁，并支持精准识别带引用的推文（带紫色"引用"标识）；移除了在气泡内部直接展开导致下方推文被挤压下移的旧逻辑，改为在鼠标点击推文气泡时，在应用中央以纯净无外边框的 Modal 悬浮层直接呈现 Twitter/X 官方嵌入推文。官方卡片采用**后台预渲染**策略：动态加载完成后在空闲时段静默预渲染最新推文，鼠标悬停气泡时该推文会被提升至渲染队列最前，因此点击时卡片通常已经就绪。每条推文在弹窗内拥有各自常驻的宿主元素，切换显示仅通过纯 CSS 类完成，iframe 全程不发生跨父节点搬移（搬移会强制 iframe 重新加载），因此不存在"占位卡片先显示、官方卡片再替换"的突兀过程；配合 Electron 主进程重写 Cache-Control 实现静态资源长达 1 年的磁盘强缓存，二次打开同一条推文可 0ms 瞬间响应。点击弹窗周边的半透明遮罩区域或按下 <kbd>Esc</kbd> 键即可随时快速关闭。
- **卡片 Header 集成头像与博主名字（无文字纯图标刷新按钮）**：Header 高度压缩至 34px，博主姓名与 handle 紧随头像（支持精确按账号提取个人专属高清头像，彻底杜绝侧边栏推荐或转推头像干扰）在 Header 原生展示，点击即可切换/修改账号；彻底去除多余的条数计数与复制按钮，抓取按钮升级为纯图标的旋转刷新按钮，推文直顶 Header。
- **滚动条默认隐藏**：每个卡片的滚动条默认保持隐形，只有当鼠标移入卡片区域时才淡入，界面更加干净简洁。
- **多样化尺寸选项 (`行 × 列`：`1×1`, `2×1 纵向双行`, `3×1 纵向三行`, `2×2 双行双列`)**：遵循“行在前、列在后”的标准几何矩阵定义。
- **智能周边内容防冲撞检测**：放大时若目标区域周边格子已有监控账号内容，自动拦截并弹出提示，同时在界面上以红色微震动高亮标出冲突卡片，提示用户先移开或清空。
- **增量智能抓取（避免重复拉取）**：抓取时自动比对已缓存的推文边界，如果遇到已经抓取过的推文立即停止滚动并完成合并；若无新推文则 ~1 秒内极速响应，大幅节省流量并降低触发限流概率。
- **排版与输入持久化保存**：Twitter handle、已抓取的推文缓存、头像以及自定义拖拽后的网格坐标均实时存入 `localStorage`，刷新应用（<kbd>Cmd + R</kbd>）原样完整还原。
- **未读新推文高亮与一键“全部已读”**：新抓取的推文气泡背景以专属柔和蓝高亮区分，用户光标悬停（Hover）到气泡上方自动消除高亮恢复原色；顶栏新增带双对勾（`✓✓`）图标的“全部已读”按钮，与网格布局选择器严格统一 28px 高度，可一键批量将所有推文标记为已读。
- **后台定时轮询（10 分钟）与时间记录**：每次抓取均自动记录时间，卡片刷新按钮 Tooltip 实时显示上次抓取时刻；页面刷新（<kbd>Cmd + R</kbd>）绝不突发抓取，智能依据上次抓取时间计算剩余倒计时进行下一次轮询。

## 运行方法

在项目根目录下执行：

```bash
npm install
npm start
```

## 功能特点

1. **Telegram 风格聊天气泡与日期分界条**：
   - 完美复刻 Telegram 对话气泡美学：气泡宽度随文字长短自适应延伸（最大 88%），去除了冗余的消息编号与内嵌头像，具体时间戳（`11:45 AM`）原生内联于文字右下角最后一行；
   - 居中胶囊日期分界条：在每一天的推文消息上方显示居中半透明胶囊日期条（如 `June 29, 2025`），严格遵循同一天的气泡仅显示一个日期头部；
   - 采用符合 IM 习惯的时间升序排布（从上到下是从旧到新，最新推文位于底部），并自动滚动至最新消息处；
   - 鼠标悬停到推文气泡上时，右上角浮现跳转原推文链接按钮（`↗`）；
   - 截断推文（>100 字符）与引用推文居中弹窗：彻底摒弃了气泡原地伸展破坏阅读流的旧交互，点击推文气泡即可在屏幕中央以纯净无边框悬浮层展示完整原始推文，避免 hover 误触；点击弹窗外围遮罩区域或按下 <kbd>Esc</kbd> 即可平滑退出。
2. **界面极致美化、主题切换与纯图标刷新按钮**：
   - 顶部导航栏配备动效 Toggle 开关（☀️/🌙），自适应系统风格与 Twitter 经典调色板；
   - 降低卡片 Header 高度至 34px，在头像旁原生展示博主姓名与 handle，点击姓名可直接激活修改输入框；
   - 配备纯图标无文字的旋转刷新按钮，去除条数计数与复制按钮，界面更加整洁干净；
   - 彻底移除卡片下方独立的“名字那一栏”（Status Bar），为推文列表腾出宝贵的纵向阅读空间；
   - 卡片滚动条默认完全隐藏，鼠标悬停时平滑显现。
3. **增量抓取机制（智能去重与极速检测）**：
   - 每次抓取优先比对当前卡片已存在的推文集合，一旦触达已知边界立即终止下滚；
   - 仅拉取比上次更新发布的“新推文”并追加到列表顶部，无新推文时 ~1 秒内闪电完成，极大减少无意义滚动与被 Twitter 风控限流的风险。
4. **多尺寸卡片与防冲突排版**：
   - 点击卡片右上角尺寸菜单，可选择 `1×1`（单格）、`2×1`（纵向双行）、`3×1`（纵向三行）、`2×2`（双行双列）尺寸；
   - 冲撞防护：检测目标位置是否被已有账号内容的格子占据，若有冲突则禁止覆盖，并通过红框震动与顶部 Toast 引导用户移开或清空。
5. **严格网格同步与自由拖拽**：
   - 切换网格布局时严格按照目标网格数量生成，清理所有多余残留格子；
   - 拖拽卡片：按住顶栏把手 `⠿` 即可自由拖动卡片重新排序；
   - 预设切换：顶部下拉菜单快速切换网格布局，按需自动整齐排列。
6. **Discord 频道监控（公开发言与私有受限频道）**：
   - 支持将任何 Discord 频道链接（如 `https://discord.com/channels/100000000000000001/200000000000000002`）直接粘贴到任何卡片输入框中；
   - 自动识别 Discord 链接，输入框前缀智能从 `@` 切换为 `#`，标题自动解析为 `#频道名` 与服务器名称；
   - **私有频道授权登录**：顶栏“登录账号”下拉菜单提供专用的 Discord 授权登录入口，使用独立的会话分区（`persist:discord_session`），登录后即可无缝监控需要成员身份的私有 Guild 频道；
   - **Telegram 风格群聊视觉美化**：采用 Telegram 风格群聊气泡，基于用户名为每位发言者分配专属色彩，连续同一人发言自动折叠作者信息，优雅渲染回复引用（`↩ author: text`），并提取图片/视频/附件/嵌入卡片标签摘要；
   - **居中消息详情弹窗**：点击任何 Discord 聊天气泡即可居中弹出消息卡片，完整阅读全文、引用信息和附件，并提供在 Discord 网页或客户端一键直达原消息的跳转按钮；
   - **单例共享 Webview、智能频道切换与状态强校验**：所有 Discord 槽位共享一个后台轻量 Webview，同服务器内秒级无缝切换，跨服务器自动重载，保留网关长连接并极大降低内存占用。具备严格的频道与消息 ID 校验及缓存自愈机制，杜绝 DOM 滞后与跨频道消息串台。
7. **Handle、频道链接、缓存与布局持久化**：
   - 每次输入 Twitter handle 或 Discord 频道链接、卡片排版自动实时保存，刷新页面（<kbd>Cmd + R</kbd>）保留所有状态与消息缓存。
8. **独立后台定时轮询与刷新频率设置（Twitter 与 Discord 分离）**：
   - 顶栏“登录账号”左侧常设齿轮设置按钮（`⚙️`），点击居中呼出偏好设置面板；
   - 分离配置：支持分别独立调节 Twitter / X 与 Discord 各自的自动刷新频率，提供常用梯度预设（`30秒`、`1分钟`、`2分钟`、`3分钟`、`5分钟`、`10分钟`、`15分钟`、`30分钟`、`1小时`）与自定义分钟输入；
   - 智能防风控提示：针对 Twitter 频率限制风险贴心提示推荐周期（建议 5 分钟以上），支持一键“恢复默认”；
   - 调度器热重载：点击保存后即刻存入 `localStorage`，定时轮询任务无缝重新排期生效，无需重启应用；
   - 记录每次抓取时间：卡片刷新图标悬停实时查看精准抓取时间（如 `上次抓取: 15:09:23`），并持久化到本地存储；
   - 页面刷新不立刻触发抓取：刷新或启动应用时，优先展示本地缓存内容，并自动计算距离上次抓取的时间差，在倒计时归零前绝不突发重复请求，彻底避免频繁刷新造成的风控限流；
   - 采用平滑依次抓取机制（非并发突发请求），账号间设置适度礼貌间隔；采用按需懒加载离屏 Webview 机制，修复 macOS 底层报错。
9. **拟人化随机延迟与防风控感知**：
   - **平滑轮询间隔**：账号间抓取保持适度缓冲等待，消除机械式的突发流量峰值；
   - **随机平滑滚动**：每次动态滚动 `650px ~ 1050px`，并加入平滑滚动动画；
   - **阅读停顿模拟**：滚动后模拟人眼停留阅读 `300ms ~ 600ms`；
   - **风控主动识别**：自动感知 Arkose Labs 人机验证挑战或 Rate limit 限制，提供即时指引。

## 项目结构

```
TheySay/
├── docs/
│   └── README_zh.md    # 中文文档
├── src/
│   ├── auth.js         # Twitter 与 Discord 登录状态检测与 IPC 授权弹窗管理
│   ├── constants.js    # 槽位上限、存储键名、分区名与轮询间隔等常量
│   ├── discord.js      # Discord 共享 Webview 客户端、SPA 路由切换与消息爬虫
│   ├── grid.js         # GridStack 网格布局计算与防冲撞调整
│   ├── popup.js        # 居中推文 Embed 悬浮弹窗与 Discord 消息详情卡片
│   ├── scraper.js      # 多源抓取分发器与后台平滑定时轮询器
│   ├── settings.js     # 偏好设置弹窗管理与 Twitter/Discord 独立刷新频率配置
│   ├── slot.js         # 卡片组件 UI、头像加载、交互与多源气泡渲染
│   ├── source.js       # 数据源识别与链接解析（Twitter 用户名 vs Discord 频道）
│   ├── storage.js      # LocalStorage 本地持久化读写封装（配置、缓存、登录态）
│   ├── theme.js        # 深色/浅色主题管理与切换
│   ├── tweet.js        # Snowflake ID 时间戳解析（支持 Twitter 与 Discord epoch）、去重与升序排序
│   ├── utils.js        # 拟人随机延迟、时间格式化与 Toast 提示
│   └── webview.js      # 离屏 Webview 进程池生命周期管理
├── index.html          # 主窗口 HTML 骨架
├── main.js             # Electron 主进程（多会话分区与登录窗口）
├── package.json        # 项目元数据与脚本配置
├── renderer.js         # 渲染进程主入口与模块协调器
├── styles.css          # 应用样式表（深浅主题、网格排版、推文与 Discord 气泡美化）
└── README.md           # 英文说明文档
```
